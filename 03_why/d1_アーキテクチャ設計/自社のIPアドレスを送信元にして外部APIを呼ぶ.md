# 自社のパブリック IP アドレスを送信元にして、外部 API を呼ぶ

- 出典：CloudTech SAP-2010（カテゴリ：分野1-ネットワーク接続戦略）
- 日付：2026-11-14
- 分野：1 アーキテクチャ設計（タスク 1.4 ネットワーク）
- 自分の解答：1番目（不正解）
- 関連：[IPv6で外へは出すが中へは入れない](IPv6で外へは出すが中へは入れない.md)（出口の作り方）

## 問題の要約（自分の言葉で）

決済アプリを AWS へ移行する。複数の VPC のプライベートサブネットにある EC2 が、外部の金融機関の API を呼ぶ。
金融機関は送信元 IP を許可リストで絞っている。会社がオンプレで長年使ってきた **自社所有のパブリック IP アドレス** を、移行後も送信元として使い続けたい。

## 要件のキーワード

- 「自社所有のパブリック IP アドレスブロックを AWS で使う」→ **BYOIP**（Bring Your Own IP）
- 「プライベートサブネットから外へ出る」→ **NAT ゲートウェイ**
- 送信元 IP を固定したい → NAT ゲートウェイに **BYOIP の Elastic IP** を付ける

## 正解

- 3番目：BYOIP で自社の IP アドレスブロックを AWS アカウントに持ち込み、そこから Elastic IP を割り当てる。各 VPC のパブリックサブネットに NAT ゲートウェイを作ってその Elastic IP を付け、プライベートサブネットの外向き通信を NAT ゲートウェイへ向ける

## なぜ正解？

- **BYOIP** を使うと、自社所有のパブリック IP アドレスを AWS の Elastic IP として使える
- プライベートサブネットの EC2 が外へ出るときは、NAT ゲートウェイが送信元 IP を **自分の Elastic IP** に変えて送る
- その Elastic IP が自社の IP アドレスなので、金融機関から見た送信元は今までと同じ。許可リストを変えずに済む
- 送信元になる IP は NAT ゲートウェイの分だけ（VPC ごとに1つなど）なので、EC2 が増えても許可リストは変わらない

## なぜ他はダメ？

| 選択肢（要点） | ダメな理由 |
| --- | --- |
| 1番目：Elastic IP を **インターネットゲートウェイ** に付け、プライベートサブネットの 0.0.0.0/0 をインターネットゲートウェイへ向ける | インターネットゲートウェイは **IP アドレスを持たない** ので、Elastic IP は付けられない。プライベートの IP しかない EC2 は、インターネットゲートウェイへ直接向けても外と通信できない（アドレスを変換する役がいない） |
| 2番目：Elastic IP をプライベートサブネットの各 EC2 に直接付ける | プライベートサブネットにはインターネットゲートウェイへの経路がないので、Elastic IP を付けても外へ出られない。経路を足せばそれはもうパブリックサブネットになる。EC2 ごとに IP が必要なので、台数が増えると許可リストも増える |
| 4番目：Direct Connect のパブリック VIF で自社の IP アドレスを広告し、外向き通信をオンプレ経由でインターネットへ出す | VPC のルートテーブルから **パブリック VIF を行き先には指定できない**。通信がわざわざオンプレを経由するので、AWS へ移行した意味も薄れる |

## 自分が1番目を選んだ理由と反省

「BYOIP の Elastic IP を付ける」までは合っていた。でも **付ける先** を間違えた。
インターネットゲートウェイは「VPC とインターネットの出入り口」で、IP アドレスを持つ機器ではない。
→ Elastic IP を付けられるのは **EC2（ENI）、NAT ゲートウェイ、NLB** など、アドレスを持つもの。

## プライベートサブネットからの出口

| 使うもの | 送信元の IP | 外から入れる？ |
| --- | --- | --- |
| NAT ゲートウェイ（IPv4） | NAT ゲートウェイの Elastic IP | 入れない |
| Egress-Only インターネットゲートウェイ（IPv6） | EC2 自身の IPv6 アドレス | 入れない |

## 一言で言うと

- 自社の IP を AWS で使う → **BYOIP**
- プライベートサブネットの送信元を固定 → **NAT ゲートウェイに Elastic IP**
- インターネットゲートウェイには IP がない。Elastic IP は付けられない
