# 分野1: クラウド向けに構築されたアーキテクチャの設計と実装（25%）

この分野で「なぜ正解？」「なぜ他はダメ？」が気になった問題のメモを置く。1問1ファイルで、`../_template.md` をコピーして書く。

ファイル名はテーマを一言で（例: `オンプレDBを止めずに移行する.md`）。

## この分野で混同しやすいもの

（問題を解いていて引っかかったペアを、ここに足していく）

| ペア | 見分け方 | メモ |
| --- | --- | --- |
| VGW（プライベート VIF） と Transit Gateway（トランジット VIF） | VPC が1つなら VGW、たくさんあるなら Transit Gateway | [専用線を足してもネット経路を変えない](専用線を足してもネット経路を変えない.md) |
| GWLB と NLB とトラフィックミラーリング | 通り道に挟んで止めたいなら GWLB。コピーを見るだけならミラーリング。NLB は宛先 IP が変わる | [複数VPCの通信をファイアウォールで透過的に検査する](複数VPCの通信をファイアウォールで透過的に検査する.md) |
| Route 53 Resolver のインバウンドとアウトバウンドのエンドポイント | オンプレ → AWS ならインバウンド、AWS → オンプレならアウトバウンド | [プライベートホストゾーンの名前が引けない](プライベートホストゾーンの名前が引けない.md) |
| enableDnsSupport と enableDnsHostnames | DNS を使えるようにするのが Support、パブリック DNS 名を付けるのが Hostnames。プライベートホストゾーンは両方必要 | [プライベートホストゾーンの名前が引けない](プライベートホストゾーンの名前が引けない.md) |
