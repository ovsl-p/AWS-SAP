# 複数 VPC の通信を、他社製ファイアウォールで透過的に検査する

- 出典：CloudTech SAP-2003
- 日付：2026-11-14
- 分野：1 アーキテクチャ設計（タスク 1.4 ネットワーク：トラフィック検査）
- 自分の解答：A・B・F（不正解。A ではなく C が正しい）

## 問題の要約（自分の言葉で）

複数の VPC からインターネットへ出る通信を、EC2 で動く他社製の仮想ファイアウォールで検査したい。
パケットは送信元・宛先の IP を変えずにそのまま渡す（透過的）。アプライアンスの設定は変えられない。
AZ やインスタンスが1つ落ちても検査を続け、自動で復旧させる。3つ選ぶ問題。

## 要件のキーワード

- 「サードパーティ製の仮想アプライアンス」「透過的」「IP を保持」→ **Gateway Load Balancer（GWLB）**
- 「複数の VPC から」→ 各 VPC に **GWLB エンドポイント** を置いてルートテーブルで向ける
- 「AZ やインスタンスの障害でも継続・自動復旧」→ **複数 AZ ＋ Auto Scaling**

## 正解

- B：検査用 VPC に GWLB を作り、アプライアンスをターゲットに登録（GENEVE で転送）
- C：アプライアンスを複数 AZ に置き、Auto Scaling で壊れたものを自動で入れ替える
- F：各 VPC に GWLB エンドポイントを作り、ルートテーブルでインターネット向けのネクストホップにする

## なぜ正解？

3つで「通り道」「検査役」「壊れても大丈夫」をそれぞれ担当している。

| 選択肢 | 役割 |
| --- | --- |
| F：GWLB エンドポイント | 各 VPC からの **入口**。ルートテーブルのネクストホップに指定できるので、アプリ側は何も変えずに通信が検査へ回る |
| B：GWLB | アプライアンスへ **振り分ける** 役。元のパケットを GENEVE で包んでそのまま渡すので、IP アドレスが変わらない |
| C：複数 AZ ＋ Auto Scaling | **可用性**。AZ が落ちても別の AZ で検査を続け、壊れたインスタンスは自動で入れ替わる |

## なぜ他はダメ？

| 選択肢（要点） | ダメな理由 |
| --- | --- |
| A：NAT ゲートウェイを通してから、アプライアンスの Elastic IP へ送る | NAT ゲートウェイは **送信元 IP を自分の IP に書き換える**ので、「IP を保持したまま」に反する。Elastic IP 宛てに送ると宛先も変わる |
| D：トラフィックミラーリングで検査 | ミラーリングは **パケットのコピー** を渡すだけ。見ることはできても、本物の通信を止めることはできない（ファイアウォールにならない） |
| E：NLB を置き、NLB の IP 宛てに送る | 宛先が NLB の IP に変わるので透過的ではない。NLB はルートテーブルのネクストホップにも指定できない |

## 自分が A を選んだ理由と反省

B と F で「透過的な転送」はできていたので、残り1つを「インターネットに出る経路」として NAT ゲートウェイを選んでしまった。
でも3つ目の要件は **「AZ やインスタンスの障害でも継続」**。可用性を担う選択肢（C）がまだ選べていなかった。
→ 複数選択の問題では、**要件を1つずつ選択肢に割り当てて**、全部の要件がカバーされているか確認する。

## GWLB と NLB とミラーリングの使い分け

| 仕組み | 通信を止められる？ | IP は変わる？ | 使う場面 |
| --- | --- | --- | --- |
| GWLB ＋ GWLB エンドポイント | 止められる（通り道に入る） | 変わらない | ファイアウォールや IPS を通り道に挟む |
| NLB | — | 宛先が NLB になる | 普通のアプリへの負荷分散 |
| トラフィックミラーリング | 止められない（コピーを見るだけ） | — | 監視、分析、侵入「検知」 |

## 調べたこと

- [Gateway Load Balancer とは](https://docs.aws.amazon.com/ja_jp/elasticloadbalancing/latest/gateway/introduction.html)：
  - レイヤー3で動き、すべてのポートの IP パケットを受け取る
  - アプライアンスとは **ポート 6081 の GENEVE** でやり取りする
  - GWLB エンドポイントはルートテーブルの **ネクストホップ** に指定できる

## 一言で言うと

- 「他社製アプライアンス」「透過的に検査」→ **GWLB ＋ GWLB エンドポイント**
- 複数選択は「要件 1つにつき選択肢 1つ」で埋まっているか確認する
